# Contributor protocol

Use English in repository content, including filenames, comments, documentation and examples. Follow the requester's preferred language in conversation.

Develop changes in a dedicated branch and worktree. Preserve unrelated work. Keep authoritative campaign evidence in persistent archives outside temporary worktrees, and never delete or rewrite historical raw evidence.

The source packages under src/agent_native_tools/_tools/ and data under paper/data/ are frozen study inputs. Preserve their original bytes or documented numeric projections. New tool versions and scientific experiments require separate identities.

Before changing a scientific operation, state its assumptions, units, domain, intended behavior and independent checks. Distinguish computation, scientific interpretation, observed use and task contribution.

Run the relevant tests, release verifier and paper-statistics reconstruction. Update checksums only after deliberate review of changes; a changed checksum is not evidence of scientific validity.

Do not launch paid model experiments, publish, push, rewrite public history or issue releases without the user's authorization. Release preparation and local verification do not authorize publication.
