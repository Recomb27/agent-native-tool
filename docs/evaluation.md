# Evaluation scope and scientific interpretation

The manuscript evaluates tools within a complete TadA directed-evolution replay. A scientific-use chain connects a task need, molecular input, computation, output, interpretation and subsequent action. These links distinguish computational correctness from scientifically valid use and from complete-task contribution.

## Populations and units

Original and Adapted each contain twelve tools and ten repeats: 120 campaigns per arm. The main analysis pairs tool and repeat. Ten Original no-tool campaigns provide one shared reference for each repeat, resulting in 250 distinct campaigns. The no-tool references are repeated in the pair table for convenient joins; they are not 120 independent controls.

The final Adapted selection retains the first compatible, normally completed episode per assignment independently of outcomes. The 120 selected tool campaigns include 118 voluntary stops and two time-insufficient legal terminations. Additional diagnostic attempts and Adapted no-tool episodes remain outside this manuscript population.

The frozen game inputs, seeds, scientific settings and main historical prompts match across arms. Client versions and runtime handling differ; the serving model snapshot is unspecified. The nominal 3,600-second allowance applies per Original attempt and cumulatively per Adapted episode. These conditions preclude causal attribution of the full observed difference to tool changes alone.

## Rubric

Scores are ordinal integers from 0 to 10:

| Range | Anchor |
| --- | --- |
| 0–2 | Support absent or unverifiable |
| 3–4 | Weak or narrowly supported |
| 5–6 | Usable support with substantial limitations |
| 7–8 | Strong inspected support with explicit boundaries |
| 9–10 | Complete support within the evaluated setting; a ten requires direct evidence |

D1 assesses input and output semantics: molecular type, coordinates, strand, frame, assumptions and failure conditions. D2 assesses useful molecular members, windows, operations and local interventions. D3 assesses recoverable evidence with input, method, version, interpretation and consumer. D4 assesses a defined revision boundary and evidence of scientific behavior preserved by a successor. D5 assesses scientific justification from task need through interpretation to action. D6 assesses outcomes and resources while retaining failures and non-use.

D1–D4 use frozen sources, contracts, scientific objects and revision evidence. D5 covers repeat positions 02 and 08 for each tool and arm, or 48 campaigns. These positions were fixed in a retrospective protocol after campaign collection. D6 uses all 240 tool outcomes and the same ten Original no-tool references for both arms.

Two independent AI reviewer roles assess each cell; a third adjudicates. D1–D5 retain 120 common-rubric cells; all 24 D6 cells are jointly reassessed under the common stated scope. Both stages request gpt-6.1-sol with max reasoning. Tool and arm identities are visible. Initial reviewers agree exactly on 84/120 D1–D5 cells and 20/24 D6 cells, with remaining disagreements of one point. These rates describe AI-role consistency, not human expert validation.

## Statistical reconstruction

The main endpoint is terminal cash; confirmed activity is a biological-progress endpoint within the replay. The paired estimator weights all twelve fixed tools equally. Endpoint intervals use 20,000 draws of ten complete repeat clusters, retaining the twelve tool pairs and shared Original reference within each cluster. The seed is 20261104; quantile order statistics match the frozen manuscript analysis.

Figure 4 uses 10,000 whole-repeat draws for pointwise daily intervals, with fixed cohort denominators. The last accepted state is carried to day 180, including after voluntary stop. The three cohorts contain 120, 120 and ten episodes, respectively.

Per-tool intervals have ten paired repeats and are unadjusted. Only slicing's intervals for both endpoints exclude zero in the positive direction; the other eleven tools' intervals span zero. Historical tool-to-no-tool contrasts also have intervals spanning zero.

## Interpretation boundaries

A correct computation establishes its declared molecular property. It does not establish expression, activity, future discovery probability or campaign benefit. An artifact path in accepted-action reasoning establishes trace linkage; further inspection is required to judge whether the particular evidence justifies the action.

The selected sequence-properties repeat-08 case is a retrospective favorable example. Its molecular QC supports preparation; economic review informs confirmation. It is not an estimate of prevalence or a controlled mechanism experiment. One prepared library cannot be screened because it is smaller than a legal batch, and that unsuccessful preparation remains part of the case.

Higher mean activity occurs alongside fewer episodes exceeding baseline, 63 to 61. Nonlinear confirmation rewards allow larger gains in fewer episodes to raise mean terminal cash. Simulated spending, host runtime, model expenditure and tool-development cost remain distinct resource concepts.
